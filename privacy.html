Privacy policy

youtube uploader · last updated November 9, 2026

What this app is

youtube uploader is a personal tool run by the owner of the Infinityespi YouTube channel on their own computer. It is not offered to the public, and it is only used to manage the owner's own channel.

What it accesses

With the owner's permission through Google sign-in, the app uses the YouTube Data API to upload videos, set their titles, descriptions, tags, thumbnails and publish schedule, and read basic channel details to confirm which channel it is signed in to.

How data is stored

The sign-in token is stored only on the owner's computer. Video files and their metadata stay on that computer until they are uploaded to YouTube. The app has no server and keeps no database of user data.

Sharing

The app does not sell, share or transfer any Google user data to anyone. Data is used only to upload and manage videos on the owner's channel. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time from your Google Account's third-party access page, which stops the app from using the account. Deleting the local token file removes the stored sign-in.

Contact

Questions can be sent through the Infinityespi YouTube channel.
